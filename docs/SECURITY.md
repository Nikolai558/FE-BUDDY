# Security Policy

The security of FE-BUDDY and its users is important. If you discover a potential security vulnerability, please report it privately so it can be investigated before being publicly disclosed.

## Reporting a Security Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues, Discussions, or Pull Requests.**

FE-BUDDY has GitHub's **Private Vulnerability Reporting** enabled. To privately report a vulnerability:

1. Navigate to the FE-BUDDY repository on GitHub.
2. Select **Security and quality**.
3. Select **Advisories** under **Reporting**.
4. Select **Report a vulnerability**.
5. Complete and submit the vulnerability report.

When submitting a report, please include as much relevant information as possible, including:

* The affected FE-BUDDY version.
* A description of the vulnerability.
* Steps to reproduce the vulnerability.
* The potential security impact.
* Any relevant logs, screenshots, or other supporting information.
* Any known workaround or mitigation, if applicable.

Security reports will be reviewed as soon as reasonably possible.

Please avoid publicly disclosing details of a reported vulnerability until it has been investigated and, when necessary, a fix has been released.

## Security Vulnerabilities vs. Bugs

Not every software issue is a security vulnerability.

Normal application bugs, crashes, AIRAC data or parsing issues, updater failures, incorrect application behavior, feature requests, and similar problems should be reported through the normal GitHub Issues system unless the issue presents an actual security concern.

If you are unsure whether an issue has security implications, reporting it privately is preferred.

## Disclosure

When a reported vulnerability is confirmed, the FE-BUDDY maintainers will determine the appropriate remediation and disclosure process based on the nature and severity of the issue.

When appropriate, information about a resolved vulnerability may be published through a GitHub Security Advisory and/or FE-BUDDY release notes after a fix is available.

Thank you for helping keep FE-BUDDY and its users secure.
