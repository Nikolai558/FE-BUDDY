# FE-Buddy 2.x manual

`Manual.html` in this folder is the manual for **FE-Buddy 2.x**. It describes 2.x's tools
(chart-recall aliases, SCT2 and FAA video-map conversions, Create GeoJSON, GeoJSON clean-up,
procedure ISRs), most of which are not in FE-Buddy 3.0 yet.

**Using FE-Buddy 3.0?** Read the [3.0 user guide](../User-Guide.md) instead, or start at
[docs/README.md](../../README.md).
